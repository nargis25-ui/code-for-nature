# Solution Overview

AI Sustainability Tracker is a web-based platform that helps users understand and improve their everyday environmental impact.

Users can track:

- Electricity usage
- Water usage
- E-waste
- AI usage

The platform processes the user's information and provides:

- Sustainability score
- Environmental impact estimates
- Personalized recommendations
- Progress reports
- AI-powered suggestions
- AI Prompt Optimizer

The system turns consumption data into simple insights so users can understand where they can make improvements.

The project combines React for the frontend, Node.js and Express.js for the backend, and AI services for personalized recommendations and prompt optimization.
