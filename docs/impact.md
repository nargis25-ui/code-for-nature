# Expected Impact

## 1. Purpose

EcoAI aims to make environmental resource usage easier to understand and encourage more sustainable decisions.

## 2. Potential Benefits

- **Awareness:** Help users review the electricity, water, e-waste, and AI usage values they record.
- **Better decisions:** Encourage users to identify resource-intensive activities and consider practical improvements.
- **Progress tracking:** Support comparisons between recorded usage entries when sufficient data is available.
- **Responsible AI:** Promote awareness of the environmental resources associated with AI use.
- **Organisational learning:** Provide a starting point for teams to discuss sustainability practices.

## 3. Measuring Impact

Potential project indicators include:

- Number of usage records submitted.
- Changes in recorded resource usage over time.
- Number of users trying the suggested sustainability practices.
- User feedback about awareness and usefulness.

These indicators require collected data and testing before any impact claims can be confirmed.

## 4. Important Limitations

Recorded usage values do not automatically prove a reduction in environmental impact. Reliable carbon estimates require suitable emission factors, clearly defined units, and documented assumptions. EcoAI should describe estimates as estimates and avoid claiming verified carbon savings without evidence.

## 5. Long-Term Vision

The long-term vision is to help individuals and organisations make informed sustainability decisions using understandable data, practical recommendations, and transparent environmental estimates.
